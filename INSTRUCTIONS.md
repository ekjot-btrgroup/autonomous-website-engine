# How it works

1. Share your brand brief: name, what you do, who it is for, and the feel you want.
2. Answer 3 quick questions: animations, colours and typography.
3. Get 10 designs picked for your brand, each with one line on why it fits.
4. Reply with the numbers of your 3 favourites.
5. Get the 3 final client-ready designs (with a Designs button to switch between them), ready for pitching or direct use.

## Running it on your own computer
Install Node 20+ (and Python 3 if you will import new HTML templates), run `npm run setup` once in this folder, open the folder in Claude Code and say hi.
