# Design Evaluation Rubric

Score each candidate on a 0–5 scale, with evidence:
1. Brand fit (25%): does the visual language fit the company's positioning?
2. Audience fit (15%): does it feel appropriate to the target audience?
3. Section/function fit (15%): does the layout serve the intended section?
4. Visual quality (15%): hierarchy, composition, spacing, typography.
5. Adaptability (10%): can content/assets/colour be adapted without destroying the design?
6. Technical compatibility (10%): can it run in the chosen output environment?
7. Responsive confidence (10%): is responsive behaviour evidenced?

Keep relevance score, technical compatibility and source quality separate. Never let a visually attractive but incompatible design outrank a usable candidate without clearly flagging the trade-off. Add a short evidence-based rationale and uncertainty note.
