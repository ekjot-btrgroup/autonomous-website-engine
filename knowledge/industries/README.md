# Industry recipes

One file per industry: `<industry-slug>.md` (same slug as `references/<industry>/`). Written once, improved with
each brief. If a brief's industry has no recipe, research first: read 4-6 strong real sites in that industry
plus 1-2 "what a <industry> website needs" guides. Learn structure and content patterns only; never copy text,
images or code. List the sources at the bottom.

## Format
```
# <Industry>
Visitors: who arrives, what they want to know first, what makes them act.
Main action: the one CTA (book, call, order, enquire...).

## Must-have sections (in a sensible order)
- hero: what it must say/show
- ...

## Nice to have
- ...

## Content checklist
- trust signals (licences, insurance, guarantees, real reviews), facts to ask the client for, legal notes

## Look and feel
- photo style, colour moods, type moods, how premium or playful, motion level
- what the best references in references/<industry>/ have in common (from npm run capture -- --list --industry <x>)

## Avoid
- clichés and mistakes seen on weak sites in this industry

## Sources
- links used for research (structure only)
