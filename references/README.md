# Reference library

Captured with `npm run capture -- <url> --industry <name> --licence <purchased|free|own>` (or `--batch <file>`).
Each folder holds `dna.json` (type, colour, spacing, sections, components, motion), `thumb.jpg`, `mobile.jpg` and
`sections/NN-<kind>.jpg`. These are references for learning proportion, rhythm and taste: never copy their text,
images or code into a design. List them with `npm run capture -- --list`.
